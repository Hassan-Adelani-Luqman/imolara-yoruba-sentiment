# Report

`main.tex` (ACL style: `acl.sty`, `acl_natbib.bst`) + `references.bib` → `main.pdf`.

**Compile (XeLaTeX is required for the Yorùbá diacritics):**
- [Tectonic](https://tectonic-typesetting.github.io): `tectonic main.tex` (downloads only the packages it needs), or
- Overleaf: upload this folder and set *Menu → Compiler → XeLaTeX*, or
- TeX Live: `latexmk -xelatex main.tex`.

Figures in `figures/` are copies of `results/figures/*.png`, regenerated by `python -m src.eda` and `python -m src.figures`.
All numbers come from `results/summary.md`, `results/test_results.md`, `results/error_analysis/` and `results/onnx_validation.md`.
